# Лаборатори 3 · Вектор өгөгдлийн дүрслэл

## 5.6.1 · Шугаман өгөгдөл унших, дүрслэх

PowerShell дээр python vector_map.py гэж ажиллуулна. Tkinter цонхонд номын жишээ өгөгдөл дүрслэгдэнэ. Нээлттэй шугам цэнхэр, хаалттай дүрс ногоон, эхлэх орой улаан байна. Зөвхөн тооцоог шалгах бол python vector_map.py --no-gui гэж ажиллуулна.

Оролт → Polyline; толгой, дугаартай объектууд, цэг таслалаар тусгаарласан координат. Боловсруулалт → оройг объект бүрээр бүлэглэж, залгаа оройнуудын зайг нэмнэ. Гаралт → оройн тоо, урт, дэлгэцийн зураглал. X ба Y-д ижил масштаб хэрэглэнэ. Дэлгэцийн Y доош өсдөг тул Y-ийн тэмдгийг эргүүлнэ.

## 5.6.2 · Цэг ба тэгш өнцөгт

python rectangle_intersections.py гэж ажиллуулахад дөрвөн цэг, дөрвөн тэгш өнцөгт үүсгэж, нийт 16 хосын үр дүнг intersections.txt файлд бичнэ. Хил дээрх цэгийг дотор гэж тооцно. Санамсаргүй үүсгүүр тогтмол seed ашигладаг тул жишээ давтагдана.

Эх сурвалж · Chaowei Yang, Introduction to GIS Programming and Fundamentals with Python and ArcGIS, §5.6.
